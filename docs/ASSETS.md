# Assets and cultural sources

## Current winter invitation

`apps/web/public/images/yalda-dusk.webp` is the current project-specific AI-generated hero, edited with the built-in imagegen tool from the initial bright winter draft following the user's feedback. It depicts a snowy winter dusk outside, warm candlelight and tea inside, pomegranates, watermelon, nuts, pastries, Hafez and Shahnameh. The flag was removed at the user's request. The final 1536-pixel WebP is approximately 412 KiB. This is illustrative generated photography.

`apps/web/public/images/lion-sun-pin.webp` was supplied by the user via [this source image](https://iranopasmigirim.com/images/store/badge-cutout.webp); the guest selector links to the user's [product page](https://iranopasmigirim.com/fa/ribbon). It is an external product asset, not an original generated asset or an endorsement. No purchase is made by the app.

The hero WebP remains unchanged. Candle and tea motion are transparent SVG overlays using the image's exact coordinates; the host explicitly requested continuous gentle motion with no playback controls. Other gift objects, snowfall, accumulated edge snow, floating book and button glint are CSS and respect reduced-motion preferences. Five public-domain Hafez couplets link to Ganjoor ghazals [232](https://ganjoor.net/hafez/ghazal/sh232), [255](https://ganjoor.net/hafez/ghazal/sh255), [115](https://ganjoor.net/hafez/ghazal/sh115), [179](https://ganjoor.net/hafez/ghazal/sh179) and [153](https://ganjoor.net/hafez/ghazal/sh153).

## Earlier design (retained source history)

`apps/web/public/images/yalda-hero.webp` is a project-specific AI-generated photographic asset, created with the built-in imagegen tool and converted from its PNG output to a 148 KB WebP using Sharp. It is a photographic rendering, not documentary photography. There are no third-party stock-photo licenses to track for this asset.

Final prompt:

> Use case: photorealistic-natural. Asset type: premium Persian Yalda invitation website hero, wide landscape 1536x1024. Create cinematic editorial still-life photography of a traditional Yalda evening: ripe whole and cut pomegranates with richly detailed ruby seeds on a dark burgundy velvet table, a brass tray, a small antique Persian poetry book without readable text, a lit ivory taper candle, subtle winter atmosphere. Composition: still life clustered left and center-left, right third very dark empty warm-black negative space for Persian website heading. Luxurious, contemporary, authentic, restrained. Warm candlelight from left, deep shadows, real organic imperfections, film grain, 50mm lens, shallow depth of field. Palette pomegranate red, muted antique gold, warm ivory, midnight plum. No people, no illustrations, no lettering, no watermarks.

The host can replace it with an HTTPS image URL. The attendance pomegranate is an accessible custom SVG; the console is a lightweight CSS rendering with a Lucide controller. Neither is an official product photograph or endorsement. Campaign imagery can be replaced by the host.

Vazirmatn, Lalezar and Geist are loaded through next/font and self-hosted in the export. Lucide icons are used throughout. The UI Button follows shadcn's Slot/CVA composition; Dialog uses accessible Radix primitives. Recharts is confined to the admin bundle.

The Hafez couplet is verified against [Ghazal 232 on Ganjoor](https://ganjoor.net/hafez/ghazal/sh232), lines beginning «بر سر آنم…». The underlying classical poem is public domain. No modern translation, interpretation, fabricated attribution or modern recording is included. The poem links to its source.

The Best Buy purchase link was verified against [Best Buy Canada's own gift-card category](https://www.bestbuy.ca/en-ca/category/best-buy-gift-cards/20277) and [gift-card help](https://www.bestbuy.ca/en-ca/help/paying-and-purchasing/gift-cards-and-egift-cards). Hosts should review purchase destinations before their event. The application does not sell cards, process payments or collect redemption codes. The CAD 1,200 target is an editable planning amount, not a quoted retail price or a claim about game availability.
